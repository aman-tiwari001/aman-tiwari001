## 👨‍💻 About Me

I enjoy solving real-world problems by applying strong **computer science fundamentals** and practical **software engineering principles**. My core strength lies in backend development designing clean and scalable REST APIs, authentication systems, databases, real-time systems, event-driven services, and data-intensive applications using Node.js, TypeScript, PostgreSQL, Redis, and Docker

I have hands-on experience deploying and operating services on **cloud VMs (Google Cloud & Azure)** using **Ubuntu**, configuring **Nginx as a reverse proxy**, and shipping containerized applications with **Docker**. I’ve set up **CI/CD pipelines using GitHub Actions**, published images to **Docker Hub**, and integrated multiple cloud services (eg. **AWS SES, GCP Pub/Sub**) in a repeatable, automated manner.

Alongside this, I also have good exposure to **AI engineering & AI-integrated full-stack product development**, where I’ve work on **GenAI, LLMs, RAG pipelines, Vector Databases, AI agents, MCP and frameworks like LangChain** to build real applications. 

Hackathons have played a major role in shaping my problem-solving mindset. Winning **multiple hackathons** has strengthened my ability to reason under constraints, make sound trade-offs, and ship quickly.
